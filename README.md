# 🏠 Hostel Buddy

**Hostel Buddy** is a real-time community management platform built for hostel residents to communicate, share resources, and manage daily interactions — all in one place.

## ✨ Features

- 🏪 **Student Marketplace** — Buy and sell campus essentials (books, electronics, stationery, vehicles) safely within the hostel community
- 🚪 **Gate Buddy** — Book hostel residents to pick up your orders at the gate; live feed of available pickers
- 💬 **Inbox / Real-Time Chat** — View and reply to marketplace messages instantly using Socket.io
- 🔐 **OTP-Based Authentication** — Secure login with email OTP verification using college credentials
- 🖼️ **Image Uploads** — Cloudinary-powered image storage with automatic compression
- 📧 **Email Notifications** — Automated emails triggered on key user interactions
- 🛡️ **Admin Panel** — Moderation dashboard to manage users, marketplace listings, and Gate Buddy activity
